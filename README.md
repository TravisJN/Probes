# Probes
Humanity has gone interplanetary. It's time to seed the galaxy.

Use the gravities of the planetary bodies to try to land your probe on the habitable world

## How to run
- Open `Probes.html` in a browser.
- If your browser blocks local asset loading, run a small static server in this folder and open `Probes.html` through it.
  - Python: `python -m http.server 8000` then open `http://localhost:8000/Probes.html`

## Dev mode
- Add `?dev=1` to the URL to enable dev mode (example: `Probes.html?dev=1`).
- Press the backtick key (`) to toggle the debug overlay.
